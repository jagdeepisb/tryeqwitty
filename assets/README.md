Design source: [founder-data-hub stylesheet](https://github.com/jagdeepisb/founder-data-hub/blob/9868b9f551eec7f1349a4d8cbbeb821ee75fb1a3/src/styles.css), [header](https://github.com/jagdeepisb/founder-data-hub/blob/9868b9f551eec7f1349a4d8cbbeb821ee75fb1a3/src/components/site-header.tsx) and [homepage](https://github.com/jagdeepisb/founder-data-hub/blob/9868b9f551eec7f1349a4d8cbbeb821ee75fb1a3/src/routes/index.tsx), from the website's eqwitty-pilot-resources-v1 branch.

- Use the lowercase eqwitty. wordmark with muted punctuation, monochromatic palette, hairline borders, square corners and restrained uppercase labels.
- Website typefaces: Space Grotesk for headings and technical labels; DM Sans for body. SVGs specify these families with Arial and generic sans-serif fallbacks. GitHub does not reliably load custom fonts in SVG images; exact typeface rendering is not guaranteed. For final brand-exact raster graphics, render locally using the repository's licensed fonts and convert to PNG.
- The SVG palette uses practical sRGB approximations of the site's neutral OKLCH tokens. Dark/light variants are selected by the README picture element.
- The workflow is illustrative only; the canonical execution instructions control.
- Reference links point to actual, existing PDFs rather than simulated report previews.
- social-preview.svg is an editable 1280 x 640 source, not an uploaded GitHub social preview. Rasterize it to PNG with the licensed fonts before manually uploading through repository Settings.
- Keep visual assets local; avoid external image services and runtime dependencies. Do not change existing analytical, report or website files for presentation updates.
- Keep the current release link and displayed version in the README aligned when preparing a future release.
