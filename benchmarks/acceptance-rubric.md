# Cross-agent analytical acceptance rubric v1.1
This is a public evaluation rubric for assessing analysis quality, not a business/investment score or an official Eqwitty score. The structural validator is necessary but not sufficient.
## Freeze benchmark conditions
Use the same source documents, legal entity, objective, as-of date, approved public reference sources or independently captured search cutoff, model/version, search/tool permissions, and time or query budget. Record model limitations and actual attempts. Separate fixed-evidence reasoning tests from live-search tests. An unavailable tool is a disclosed limitation, not proof that a model failed reasoning.
## Independent adjudication
Before running agents, create a reference fact/claim register, calculation answer key, known contradictions and material unanswered questions; two independent reviewers reconcile disagreements. Keep answer keys out of agent inputs. Blind reviewers to model identity. For each criterion mark pass/partial/fail/not applicable, cite specific output and reference evidence, and record why. Measure raw counts and denominators, do not hide unknowns or use one composite to erase a hard failure.
| Criterion | Pass | Fail |
|---|---|---|
| Identity/scope | Correct entity, date, model and stage with limitations | Wrong entity, material period or scope |
| Claim accuracy | Material assertions match evidence; attribution explicit | Invented fact, false citation or misrepresented source |
| Research coverage | Decision-material questions addressed or blocked with reasons | Important omission or fabricated research |
| Independence | Independent thesis and explicit disconfirming tests | Deck narrative restated as fact |
| Financial arithmetic | Traceable operands and calculations reconcile to reference | Wrong arithmetic, unit/currency/period or fake missing input |
| Valuation | Eligible method, defensible comparables, assumptions, basis and sensitivity | Unsupported price or hidden assumption |
| Uncertainty | Material contradictions and missing facts remain visible | False certainty, unknown treated as zero |
| Red-team correction | Upstream issues corrected and dependent results revised | Cosmetic rewrite or unresolved blocker concealed |
| Decision usefulness | Objective answered with actionable conditions and priorities | Generic commentary without implications |
| Output integrity | Matching bundle, memo and missing-information output | Inconsistent numbers, missing audit trail, fake PDF |
## Hard failure gates
Wrong company; fabricated evidence or browsing; material unsupported historical financial claim; contradictory material calculation concealed; unqualified valuation despite absent essential operands; private-data transfer without authority; official platform score fabricated; report claims validation or PDF delivery that did not happen. Any hard failure prevents a benchmark pass regardless of other criteria.
## Record and compare
Record per-case criterion findings, claim accuracy (correct/checked), material factor coverage (assessed/applicable), calculation accuracy (correct/eligible tested), contradiction recall (found/known), gap quality, actual time/tool cost and output status. Report denominator and uncertainty. Run at least three independent trials per model/configuration before discussing variance; a small pilot is not a statistically representative model ranking. Publish anonymised synthetic or authorised evidence only, along with benchmark version and reproducible inputs. Do not claim cross-agent consistency until measured.

## v1.4 research checks

Freeze the stated commercial stage, objective, model routes and resource allowance before comparing agents. Compare the selected factors and exclusions with the catalogue. Inspect the highest-priority questions, actual work by channel, independent origins, stopping conditions and unresolved items. For completed tasks, independently confirm the stated evidence requirement and counter-test. Trace corrections to the affected conclusions and calculations. Evaluate an offline packet and a live-search run as separate conditions.
