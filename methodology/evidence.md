# Evidence and research discipline v1.1
Use stable IDs. Evidence records must include publisher, title, locator (page/cell/URL), date accessed, origin group, evidence type and exact extract or faithful paraphrase. Preserve original language where meaning matters. Never represent an extraction as independently verified just because it appears in a company file.

| Grade | Definition | Permitted use |
|---|---|---|
| A | Direct authoritative primary record with correct entity, period and definition | Strong support for the specific fact recorded; not for unrelated claims |
| B | Independent credible corroboration with traceable method | Support qualified factual inference |
| C | Company statement, promotional source or indirect material | Attribute to origin; not independent corroboration |
| D | Weak, ambiguous, snippet-only or unverified source | Research lead only |
| U | No usable evidence | Unknown; never a negative rating |

Grade is specific to the claim. A corporate registry verifies incorporation, not product demand. Two outlets copying the same release count as one origin. A claim classified verified must have at least one independent A/B source supporting the proposition; record opposing evidence and use contradicted/disputed where warranted. The validator checks referential rules, not whether the cited excerpt is true or genuinely relevant. A calculation uses source-bound operands and explicit formula; a model inference must be labelled. Research tasks record queries and actual attempts or blocking reason, never fabricate tool execution. Record source accessibility and gaps; no automatic source count threshold substitutes for relevance.
