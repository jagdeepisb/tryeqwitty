# Eqwitty Open Diligence Standard v2.2.0

The optional decision brief leads with the investment or financing decision and retains material findings, numerical summaries, evidence links and requests. The full assessment retains the detailed research and financial schedules. The release package contains both formats and their automated PDF verification.

The public examples distinguish an illustrative financing decision from synthetic regression fixtures. The archived Codex pilot is a single-configuration repeatability measurement, not independent expert validation or evidence of model superiority. The prospective evaluation requirements describe work that remains to be performed.

Analytical bundle 1.4, financial model 1.2 and structured report 1.3 are unchanged. Earlier immutable releases remain available.
