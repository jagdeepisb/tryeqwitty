# Eqwitty Open Diligence Standard v2.2.1

Both full assessments and decision briefs use clearer financial labels while preserving the analytical record, numerical values and evidence links. Repetition is reduced without merging distinct evidence contexts. The public documentation separates synthetic regression fixtures from a scoped, source-linked Monzo decision note.

Release verification instructions now point to the current version; the new `verify_release.py` entry point retains compatibility with the earlier command. The automated reference package includes full and brief PDFs and HTML.

Analytical bundle 1.4, financial model 1.2 and structured report 1.3 are unchanged. The historical benchmark is unchanged and does not establish independent expert validation or model superiority.
