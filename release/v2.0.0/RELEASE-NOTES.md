# Eqwitty Open Diligence Standard v2.0.0

This release pins the analytical, financial, research and structured reporting contracts, with conformance checks for a validated bundle and a reconciled report. Older formats retain their existing validation and export paths.

The release evidence contains a manifest and checksums, the exact replay of the v1.5 pilot, and three reproducible reference reports. The pilot covered one Codex configuration and one live registry task. Maintainer release acceptance covers the published gates and reference artifacts.

Original code is available under MIT and original methodology under CC BY 4.0. Font and registry reuse terms appear in the notices.
