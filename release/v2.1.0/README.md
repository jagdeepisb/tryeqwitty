# Eqwitty Open Diligence Standard v2.1.0

[Published v2.1.0](https://github.com/jagdeepisb/tryeqwitty/releases/tag/v2.1.0). The analytical bundle remains 1.4, financial model 1.2, structured report 1.3 and frozen benchmark 1.5. No analytical formula, factor or evidence contract changes.

[Profile](profile.json) · [Editorial requirements](../../report-spec.md#reader-facing-publication-quality-mandatory) · [Compatibility](../COMPATIBILITY.md) · [Release notes](RELEASE-NOTES.md)

The mandatory reader-facing rules apply to all exports. Evidence references link to source records; technical provenance remains in the analytical record and receipt. Visible reports must not contain em dashes or implementation commentary. Material limitations remain visible. The official platform is not represented by these independent assessments.

## Acceptance

All existing analytical, reconciliation, financial and frozen benchmark gates remain required. The candidate additionally requires the editorial regression tests, linked PDF destinations, embedded fonts, text checks and visual inspection of all three newly generated reference reports. Record the exact reviewed artifacts and their checksums before publication. See [PDF review](PDF-REVIEW.md).

Use the commands and conformance procedure described in the [v2.0.0 release documentation](../v2.0.0/README.md) with the v2.1.0 checkout and the new profile. Old releases remain immutable. The published assets and their checksums are available from the tagged release.
