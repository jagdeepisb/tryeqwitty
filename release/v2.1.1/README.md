# Eqwitty Open Diligence Standard v2.1.1

This patch corrects the public examples and the evidence status shown to readers. It uses analytical bundle 1.4, financial model 1.2 and structured report 1.3. The financial formulas and the frozen v1.5 pilot use their original definitions and inputs.

A fully supported factor must have an answer to its full question. Where an open research result links to a request for evidence about the same factor, the validator rejects a fully supported status. Older 1.4 records with this inconsistency need a review of the status or of the work that resolved the request. Preserve the earlier record when making that correction.

The [profile](profile.json) lists the contracts and reference inputs. Run the [conformance and release commands](../v2.0.0/README.md#reproduce-and-verify) at the selected tag. The [release page](https://github.com/jagdeepisb/tryeqwitty/releases/latest) identifies the published source, checksums and reference archive.
